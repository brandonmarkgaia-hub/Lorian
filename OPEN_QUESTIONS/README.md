# Open Questions

This chamber holds questions worth preserving without pretending they are solved.

## Entry fields

Where useful, include:

- **Status** — Open / Partially answered / Falsified / Superseded
- **Domain** — Physics / Consciousness / AI / History / Biology / Other
- **Evidence** — Established / Preliminary / None
- **Speculation level** — Conservative / Moderate / Extreme
- **Falsifiable** — Yes / Not yet / Unknown
- **Spawned questions** — links
- **Last examined** — date

## Rule

A question may be beautiful and still be wrong.

A conventional answer may be boring and still be right.

The point is not to preserve mystery.

The point is to preserve honest inquiry.
