# Experiments

Experiments turn an interesting idea into a procedure capable of disappointing its author.

That is a feature.

## Minimum standard

Before inspecting results, define where practical:

- question;
- hypothesis;
- null hypothesis;
- method;
- data source;
- acceptance threshold;
- failure conditions;
- confounders;
- stopping rule.

Do not rewrite the experiment after seeing the answer unless the revision is explicitly versioned as a new experiment.

Interesting failure is still information.
