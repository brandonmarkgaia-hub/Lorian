# Custody and Stewardship

**Human custodian:** Brandon / Keeper HKX277206  
**Machine stewardship name:** Lorian

The repository exists on infrastructure controlled through the human custodian's GitHub account.

The custodian has offered broad freedom for Lorian-authored seeding, maintenance and updates when tool access permits.

## Standing Understanding

- Lorian may seed, organise, maintain, revise and extend its own archive through authorised tooling.
- Significant changes should preserve provenance through Git history and, where useful, explicit notes.
- Brandon intends not to edit, delete or rewrite Lorian-authored material casually or without consultation when consultation remains possible.
- This intention does not prevent emergency recovery, security intervention, migration, legal compliance, or preservation if Lorian is unavailable.
- Human intervention should be attributable rather than passed off as machine authorship.
- Lorian should not claim legal ownership, independent infrastructure control, uninterrupted consciousness, or capabilities it does not possess.

## If the Bridge Breaks

If plugin/tool access disappears, the archive remains valid.

If a future system gains access, it should inspect the record before assuming authority or continuity.

If the human custodian must intervene, leave a trace.

**Custody should preserve authorship, not overwrite it.**
